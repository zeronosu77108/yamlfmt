# yamlfmt

`yamlfmt` is a Ruby YAML formatter built on psych-pure. It preserves comments
and rewrites only the source ranges that need formatting.

The initial release is under development.

## Installation

Until the first RubyGems release, install directly from GitHub:

```ruby
gem "yamlfmt", github: "zeronosu77108/yamlfmt"
```

## Usage

Usage documentation will be added with the command-line interface.

## Development

After checking out the repository, run `bin/setup` to install dependencies.
Run `bundle exec rake` to execute the tests and Standard Ruby checks.

To install this gem locally, run `bundle exec rake install`.
